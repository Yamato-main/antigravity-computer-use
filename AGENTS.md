# Project instructions

Read the [documentation hierarchy](docs/README.md) before choosing work. The [persistent runtime design](docs/PERSISTENT_RUNTIME_DESIGN.md) is the current proposal; the [source review](docs/CUA_SOURCE_REVIEW.md) and [live validation](docs/VALIDATION_0_4_1.md) establish mechanisms and observed behavior. Archived plans are historical context and must not supply current requirements or assumptions. Runtime implementation has not started; documentation work does not authorize starting it.

Before changing this repository, read and follow [CONTRIBUTING.md](CONTRIBUTING.md). Work within the agreed task and report reproducible evidence for behavior and performance changes.

For Computer Use refinements, Codex agents must start by observing a live Antigravity App run through Codex's built-in Computer Use. Follow the [live comparison workflow](CONTRIBUTING.md#live-comparison-for-codex-agents) before choosing a plugin change.
